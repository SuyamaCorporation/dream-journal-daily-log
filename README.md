# Dream Journal Daily Log & Pattern Tracker

## 概要
毎朝の夢の内容・感情・登場人物・場所・タグをテキスト入力して記録。カレンダーヒートマップ・タグクラウド・感情分布・月次集計グラフで夢のパターンを分析するダークテーマのジャーナルアプリ。

## 機能
- 夢の記録: 日付・タイトル・詳細テキスト・感情タグ（9種）・登場人物・場所・カスタムタグ・明晰度評価（1-5星）
- ジャーナル一覧: テキスト検索・感情フィルタ・エントリ詳細表示
- エントリ編集・削除
- 分析ダッシュボード:
  - カレンダーヒートマップ（過去15週・記録日を色密度で表示）
  - タグクラウド（頻度=文字サイズ）
  - 感情分布パイチャート
  - 月次ドリームカウント棒グラフ
  - 登場人物・場所のトップリスト
  - 合計夢記録数・明晰夢数・連続記録日数
- JSON エクスポート
- localStorage で全データ永続化

## 使い方
1. 「New Entry」タブで夢を記録
2. 「Journal」タブで過去の記録を閲覧・検索
3. 「Analytics」タブでパターン分析を確認
